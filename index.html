What a 1-on‑on video call gets wrong

Chatter3 is a free English conversation app: two learners, five minutes, one video call. This is the engineering log of the six bugs we found in it — the ones a store reviewer pressed, a partner never arrived for, and a data export disappeared into.

Six notesArkWeb, Cloudflare Workers, WebRTCEvery fix has a testNo invented numbers

The notes

Each one is a bug that reached production and was found by a person, not by a unit test. The symptom comes first, because that is the part that is hard to reproduce later.

ArkWeb · HarmonyOS

A frozen screen, and the sentence in the documentation that said why

The share button froze the app. The cause was a window request answered with a controller that no component ever rendered — a documented way to block the render process.

ArkWeb · Permissions

The camera was granted, and the app still said it was denied

A protected resource has two permissions, not one: the system‑level one and the one the page asks the host for. The shell never answered the second, so every request was refused.

Cloudflare Workers · WebSockets

A Durable Object that forgot one of the two people

The sockets stayed open, but a field holding them was lost when the object was evicted. One side sent everything; the other side received nothing.

Cloudflare Workers · Routing

A wider route ate a GDPR export request

“Export my data” answered User not found for every signed‑in user, because a generic /api/user/ handler sat above it in the file.

WebRTC · Telemetry

“Your network blocked the call” when the other person never arrived

The failure reason was read out of the ICE statistics. But a connection that was never offered makes no candidates at all — and every statistic then looks like a blocked network.

WebRTC · Time

The timer that started before the call did

The countdown began at the moment of the match, so the waiting counted as conversation. Fixing it also uncovered a sign error that made two phones count down to different seconds.

Why this is public

These are the kinds of bug that every video call app has and none of them write down. The notes are here because the fixes are more useful to the next person than the app is, and because a page with real code on it is a page a search engine can quote.

One of them is now a package of its own: chatter3-call-clock — the call timer, MIT, no dependencies, with the tests that caught the sign error. It is on npm as well, so npm install chatter3-call-clock is the short way to get it, and the release is archived with a DOI on Zenodo.
